# Guía de usuario inicial

**Objetivo:** Facilitar la adopción de la plataforma por parte de los usuarios finales.

- **Documentación de Flujos**: Se redactaron guías paso a paso para el registro, la búsqueda de servicios mediante filtros y la realización de una reserva.
- **Componentes de Ayuda**: Se integraron elementos visuales como "Tooltips" y mensajes informativos para guiar al usuario en las acciones más complejas.
