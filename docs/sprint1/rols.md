# Asignación de roles y tareas

**Objetivo:** Determinar responsabilidades de cada miembro del equipo. Nosotros hemos ido gestionando los roles y las tareas en base a como hemos ido acabando cada uno de nuestras tareas. Y en base a esas tareas cada uno sabia lo que tenia que ir haciendo.

## Roles y tareas
Estas son las que teniamos pensado al principio del proyecto. Pero como el proyecto se desarrolla en equipo, cada uno tiene su rol y tareas. AL final somos los dos que hemos realizado todo el proyecto. Y hemos estado tocando todo el codigo de cada parte del proyecto.

- **Project Manager / Scrum Master:** Coordinación general y seguimiento de tareas. Pero en nuestro caso realizamos los 2 la parte de gerencia del proyecto 
- **Frontend Developer:** Diseño e implementación de la interfaz y formulario de contacto. Y muchos másque hemos estado haciendo en la parte del frontend
- **Backend Developer:** Configuración de entornos, y creación de una base ded datos, la cual hemos creado para poder gestionar los datos que tenemos en la base de datos mediante la api que también hemos creado y podemos gestionar nosotros.
